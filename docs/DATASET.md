# Dataset provenance and acquisition

Inspected 26 October 2026. AWID's current form is https://icsdweb.aegean.gr/awid/download and requires institutional email, affiliation, confirmation and approval. The originally supplied `/download-dataset` path returned 404. The user confirmed the request; the website estimates 1–3 days. No AWID file has been received. AWID is not the source of the current scores.

The accessible alternative is https://github.com/hsngccu/WPA3-dataset at revision `e07113327e2012a861f3e273e10ed9b02f0491f4`. The repository describes its empirical Wi-Fi handshake attack dataset, includes raw PCAPs and Wireshark CSVs, and carries an MIT license (copyright 2024 HSNG). Exact file URLs, Git blob identifiers and SHA-256 checksums are retained in `sources/WPA3_MANIFEST.json`. License text is `sources/WPA3_DATASET_LICENSE.txt`. We downloaded only data, README and license, not attack tools.

Chosen subset: all 62 CSV segments under `The_WPA3_Dataset_csv/2. Deauth/`, naturally ordered by segment number. These are portions of a single Deauth recording, not 62 independent attack runs. CSV labels observed: `Normal` (116,799 packets) and `Deauth` (5,507), total 122,306. One raw PCAP segment is included locally for packet-path validation; it is not an independent evaluation capture. Raw downloads (~119 MB) remain gitignored; reproduce with `python scripts/download_public_dataset.py`.

## Schema and ground truth

The adapter requires `frame.time_epoch`, `frame.len`, `wlan.fc.type`, `wlan.fc.subtype`, `Label`. Optional fields: transmitter `wlan.ta`, receiver `wlan.ra`, `wlan.bssid`, retry `wlan.fc.retry`, signal `radiotap.dbm_antsignal`, frequency `radiotap.channel.freq`, reason `wlan.fixed.reason_code`. Unknown labels fail explicitly. This version uses numeric radio metadata and excludes categorical packet identifiers from predictive inputs. Missing signal is NaN; ratios/counts come only from observed packets.

Ground truth is the publisher's packet Label. An aggregated window is malicious when any included packet has a malicious publisher label; original label set and malicious fraction are retained. We have not independently audited the author's labeling method. We do not label a packet malicious simply because it is a deauthentication. This distinction preserves legitimate deauthentications in normal ground truth. Invalid timestamps/types/lengths are skipped; unknown labels and out-of-order timestamps are rejected. The module streams 20,000-row chunks instead of loading the full raw CSV collection into RAM. It materializes the much smaller aggregated feature table for sklearn.

For this run, 6,286 eligible windows were produced (5,628 normal, 658 malicious). There are 1,984 duplicate predictive rows before splitting. Timestamps, MACs, frame sequence, publisher label, source path, original label and malicious fraction never enter the feature allowlist. Separate 60-second blocks have their first full observation window purged, so windows in different blocks share no packets. A fixed seed-42 split selects whole blocks. One recording is still a weak basis for generalization; see MODEL.md.

## Importing future AWID data

Use the dashboard inspector or `wids.dataset.inspect_csv(path)` to inspect exact columns and example values. Match all required packet fields and review observed label vocabulary. Current AWID3 versions may fit this Wireshark adapter, but this is not guaranteed before receiving files. Supply correctly ordered segments from one recording to `python -m wids.cli prepare ... --source "Full dataset citation" --recording-id capture-name`. Combine independently prepared recordings only with matching schema/window/step metadata and unique recording/group IDs. For independent-session evaluation use recording IDs as groups instead of temporal blocks and retain provenance. Headerless AWID2 is deliberately unsupported until an explicit reviewed column mapping exists. Do not fit a model on arbitrary AWID CSV features and pass this project's packet features into it.

The matched genuine PCAP segment `2. Deauth_00056_20240417001459.pcap` and CSV `2. Deauth_57.csv` both contain 2,000 packets. Their 302 aggregated observations agree on all 16 predictive features. Publisher RSSI values differ from Scapy in multi-antenna Radiotap namespaces, so `mean_rssi` and `std_rssi` remain extracted analysis values but are excluded from ML. The comparison is reproducible with `python -m scripts.verify_feature_compatibility`.

Authorized local captures need genuine independently recorded ground truth in the supported CSV schema. Never derive supervised labels from the same threshold used for detection. Synthetic fixtures are limited to software tests and are visibly marked in storage and UI.
